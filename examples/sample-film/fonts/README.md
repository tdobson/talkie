# Label font

`label.ttf` is Work Sans, from https://github.com/weiweihuanghuang/Work-Sans. It is licensed
under the SIL Open Font License, version 1.1 (https://openfontlicense.org).

Talkie draws labels as outlines at build time, so the built film does not carry the font file.
To use another font, replace `label.ttf` or set `font` in `talkie.config.ts`.

The licence text is in `OFL.txt` here. The font keeps the OFL; the rest of the repo is AGPL.
