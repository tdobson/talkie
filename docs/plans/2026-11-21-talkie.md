# Talkie Implementation Plan

> **For agentic workers:** This plan is executed by two saved workflows:
> `.claude/workflows/talkie-spike.js` (Phase 0) and `.claude/workflows/talkie-build.js` (Phases 1 and 2).
> Every task is one agent spawn. Each build task is preceded by a **Haiku explorer** (`Explore`, read-only),
> built by a **Fable 5.2 low-effort coder** in its own git worktree, then reviewed, fixed once if needed,
> and merged by an integrator at the end of its wave.
>
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Talkie: a format, reference player, authoring library and CLI for narrated vector
films (Lottie pictures, one narration track as the clock) that play like video on web and React Native.

**Spec:** `docs/superpowers/specs/2026-11-21-talkie-design.md` (read it before any task).

**Architecture:** yarn 4 workspace monorepo. `@talkie/format` (types, validation, timeline maths,
reading and packing films) underpins `@talkie/author` (scene code to Lottie JSON), `@talkie/player`
(web component), `@talkie/react` (React 19 wrapper), `@talkie/cli` (voice, build, check, qa, dev,
export) and, in phase 2, `@talkie/react-native`.

**Tech stack (matches `~/dev/next-app-template`):** Node 22+, yarn 4.18 (`nodeLinker: node-modules`),
TypeScript 7.0.2 (tsgo, the `tsc` binary), oxlint + oxfmt with `oxc-config-mantine`, Jest 30 with
`@swc/jest` and Testing Library, Playwright, esbuild for bundles. React 19.3, Next 16.4 and Mantine 9.8
in the example app. Runtime libraries: `@lottiefiles/dotlottie-web`, `fflate`, `opentype.js`,
`svgson`, `svgpath`, `commander`, `jiti`, `@resvg/resvg-js`, `playwright-core`. ffmpeg 7 on the path.

**Codebase:** this repo only (`video-feedback.tdobson.net`, branch `svg-animation-codec-or-container`).
Paths below are relative to the repo root.

## Ground rules for every agent

1. **Low priority, always.** This machine (tragicomix) is Tim's shared desktop. Every heavy tool
   runs as `nice -n19 ionice -c2 -n7 <cmd>`: tsc/tsgo, oxlint, oxfmt, jest, playwright, esbuild,
   next build, ffmpeg, yarn install. The root and package `package.json` scripts already carry the
   prefix (Task 1), so prefer `yarn <script>` over calling tools directly. If you must call a tool
   directly, type the prefix. Jest runs with `--maxWorkers=2`; Playwright with `workers: 2`.
2. **No film renders on tragicomix.** `talkie export` refuses to run here unless `--allow-here`
   is passed, which only the tiny test exports use (320x180, 2 s). Full exports and the spike's
   H.265 chapter encode run on asterix (`ssh asterix`), still niced.
3. **Dependencies are added once, in Task 1.** Later tasks must not add dependencies or change
   `yarn.lock`. If a task truly needs a new package, stop and report it as a blocker. (Phase 2
   Task 16 is the one exception: it adds the React Native dependencies.)
4. **Branch per task.** In your worktree, run `git switch -c talkie/<task-id>` first, commit as you
   go, and leave the branch committed when you finish. Return the branch, worktree path and HEAD SHA.
5. **TDD.** Write the failing test, see it fail, implement, see it pass, commit.
6. **No em or en dashes** in any user-facing string, doc, caption or comment that a viewer could see.
7. **Do not edit files owned by another task** in the same wave (listed per task). Shared stubs
   created in Task 1 exist so parallel tasks never touch the same file.
8. **Determinism.** No `Date.now()`, `Math.random()` or wall-clock reads in build output paths.
   The same inputs must give byte-identical `dist/` output.

- [ ] **Step 4: implement `validate.ts`:**

```ts
import { TALKIE_MAJOR, type TalkieFilm } from './types';
export interface ValidationError { path: string; rule: string; message: string }
export type ValidationResult = { ok: true; film: TalkieFilm } | { ok: false; errors: ValidationError[] };
const EPS = 1e-3;
export function isSafeRelativePath(p: unknown): p is string {
  return typeof p === 'string' && p.length > 0 && !p.startsWith('/') && !p.includes('\\')
    && !/^[a-z][a-z0-9+.-]*:/i.test(p) && !p.split('/').some((seg) => seg === '..' || seg === '' || seg === '.');
}
const num = (x: unknown): x is number => typeof x === 'number' && Number.isFinite(x);
export function validateFilm(input: unknown): ValidationResult {
  const errors: ValidationError[] = [];
  const err = (path: string, rule: string, message: string) => { errors.push({ path, rule, message }); };
  if (typeof input !== 'object' || input === null || Array.isArray(input)) return { ok: false, errors: [{ path: '', rule: 'type', message: 'talkie.json must be a JSON object' }] };
  const f = input as Record<string, any>;
  if (!Number.isInteger(f.talkie) || f.talkie < 1) err('talkie', 'required', 'talkie must be the integer format version');
  else if (f.talkie > TALKIE_MAJOR) err('talkie', 'version', `film uses format version ${f.talkie}; this reader supports up to ${TALKIE_MAJOR}`);
  if (typeof f.title !== 'string' || f.title.length === 0) err('title', 'required', 'title must be a non-empty string');
  if (!num(f.duration) || f.duration <= 0) err('duration', 'required', 'duration must be a positive number of seconds');
  if (!Array.isArray(f.size) || f.size.length !== 2 || !f.size.every((n: unknown) => Number.isInteger(n) && (n as number) > 0)) err('size', 'required', 'size must be [width, height] in whole pixels');
  if (!Array.isArray(f.audio) || f.audio.length === 0) err('audio', 'required', 'audio must list at least one track');
  else {
    f.audio.forEach((a: any, i: number) => {
      if (!isSafeRelativePath(a?.src)) err(`audio[${i}].src`, 'path', 'audio src must be a relative path inside the film');
      if (typeof a?.type !== 'string' || !a.type.startsWith('audio/')) err(`audio[${i}].type`, 'required', 'audio type must be an audio/* MIME type');
    });
    if (!f.audio.some((a: any) => typeof a?.type === 'string' && a.type.startsWith('audio/mp4'))) err('audio', 'aac-required', 'every film must include an audio/mp4 (AAC) track');
  }
  if (!Array.isArray(f.scenes) || f.scenes.length === 0) err('scenes', 'required', 'scenes must list at least one scene');
  else {
    const ids = new Set<string>();
    let prevEnd = 0;
    f.scenes.forEach((s: any, i: number) => {
      const p = `scenes[${i}]`;
      if (typeof s?.id !== 'string' || !s.id) err(`${p}.id`, 'required', 'scene id must be a non-empty string');
      else if (ids.has(s.id)) err(`${p}.id`, 'unique-id', `scene id ${s.id} is used twice`);
      else ids.add(s.id);
      if (!isSafeRelativePath(s?.src)) err(`${p}.src`, 'path', 'scene src must be a relative path inside the film');
      if (!num(s?.start) || !num(s?.end) || s.end <= s.start) { err(p, 'range', 'scene needs numeric start < end'); return; }

    if (typeof c?.title !== 'string' || !num(c?.start) || c.start < 0 || (num(f.duration) && c.start >= f.duration)) err(`chapters[${i}]`, 'required', 'chapter needs a title and a start inside the film');

    if (typeof c?.lang !== 'string' || typeof c?.label !== 'string') err(`captions[${i}]`, 'required', 'captions need lang and label');
```

```ts
export interface ScenePosition { index: number; scene: TalkieScene; localTime: number }
/** Scene containing film time t. A time exactly on a boundary belongs to the later scene. */
export function sceneAt(film: TalkieFilm, t: number): ScenePosition {
  const s = film.scenes;
  const time = Math.min(Math.max(t, 0), film.duration);
  let lo = 0, hi = s.length - 1;
  while (lo < hi) { const mid = (lo + hi + 1) >> 1; if (s[mid].start <= time) lo = mid; else hi = mid - 1; }
  return { index: lo, scene: s[lo], localTime: Math.min(time - s[lo].start, s[lo].end - s[lo].start) };
}

}

  let idx = -1;
  for (let i = 0; i < film.chapters.length; i++) if (film.chapters[i].start <= t) idx = i;
  return idx;
```

```ts
import type { Ease } from './model';
export const HANDLES: Record<Ease, { o: [number, number]; i: [number, number] }> = {
  linear: { o: [0, 0], i: [1, 1] }, in: { o: [0.42, 0], i: [1, 1] }, out: { o: [0, 0], i: [0.58, 1] }, inOut: { o: [0.42, 0], i: [0.58, 1] },
};
/** y for x on the cubic bezier (0,0) o i (1,1), solved by bisection (deterministic, 30 iterations). */
export function easeAt(ease: Ease, x: number): number {
  const { o, i } = HANDLES[ease];
  const bx = (t: number) => 3 * (1 - t) ** 2 * t * o[0] + 3 * (1 - t) * t ** 2 * i[0] + t ** 3;
  const by = (t: number) => 3 * (1 - t) ** 2 * t * o[1] + 3 * (1 - t) * t ** 2 * i[1] + t ** 3;
  let lo = 0, hi = 1;
  for (let n = 0; n < 30; n++) { const mid = (lo + hi) / 2; if (bx(mid) < x) lo = mid; else hi = mid; }
  return by((lo + hi) / 2);
}
```

```ts
/** audio.currentTime updates coarsely in some browsers; extrapolate between updates, never run ahead by more than 250 ms, never step backwards by less than 300 ms (a real seek). */
export class SmoothClock {
  private media = 0; private wall = 0; private last = 0;
  constructor(private now: () => number = () => performance.now()) {}
  read(m: MediaLike): number {
    const wall = this.now();
    if (m.paused || m.seeking || m.currentTime !== this.media) { this.media = m.currentTime; this.wall = wall; }
    let t = m.paused || m.seeking ? m.currentTime : Math.min(this.media + ((wall - this.wall) / 1000) * m.playbackRate, this.media + 0.25);
    if (!m.paused && !m.seeking && t < this.last && this.last - t < 0.3) t = this.last;
    this.last = t;
    return t;
  }
}
```

```ts
import { spawn } from 'node:child_process';
/** Run a command at nice 19 / ionice class 2 level 7; resolve stdout and stderr, reject on a non-zero exit. */
export function runLow(cmd: string, args: string[], opts: { input?: Uint8Array } = {}): Promise<{ stdout: Buffer; stderr: string }> {
  return new Promise((resolve, reject) => {
    const p = spawn('nice', ['-n', '19', 'ionice', '-c', '2', '-n', '7', cmd, ...args], { stdio: ['pipe', 'pipe', 'pipe'] });
    const out: Buffer[] = []; let err = '';
    p.stdout.on('data', (d) => out.push(d)); p.stderr.on('data', (d) => { err += d; });
    p.on('error', reject);
    p.on('close', (code) => (code === 0 ? resolve({ stdout: Buffer.concat(out), stderr: err }) : reject(new Error(`${cmd} exited ${code}: ${err.slice(-2000)}`))));
    if (opts.input) p.stdin.end(opts.input); else p.stdin.end();
  });
}
```

```tsx
'use client';
import { useEffect, useImperativeHandle, useRef, type CSSProperties, type Ref } from 'react';
import type { TalkiePlayerElement } from '@talkie/player';
export interface TalkiePlayerProps {
  src?: string; source?: Blob | ArrayBuffer | Uint8Array; controls?: boolean; autoPlay?: boolean; start?: number;
  captions?: string; poster?: string; wasmUrl?: string; accentColor?: string; className?: string; style?: CSSProperties;
  ref?: Ref<TalkiePlayerElement | null>;
  onPlay?: () => void; onPause?: () => void; onEnded?: () => void; onTimeUpdate?: (t: number) => void;
  onChapterChange?: (index: number) => void; onError?: (e: Error) => void; onLoadedMetadata?: (duration: number) => void;
}
export function TalkiePlayer({ ref, source, accentColor, style, onPlay, onPause, onEnded, onTimeUpdate, onChapterChange, onError, onLoadedMetadata, ...attrs }: TalkiePlayerProps) {
  const el = useRef<TalkiePlayerElement | null>(null);
  useImperativeHandle(ref, () => el.current!, []);
  useEffect(() => { void import('@talkie/player').then((m) => m.defineTalkiePlayer()); }, []);
  useEffect(() => { if (el.current && source) el.current.source = source; }, [source]);
  useEffect(() => {
    const node = el.current; if (!node) return;
    const map: Array<[string, (e: Event) => void]> = [
      ['play', () => onPlay?.()], ['pause', () => onPause?.()], ['ended', () => onEnded?.()],
      ['timeupdate', () => onTimeUpdate?.(node.currentTime)], ['chapterchange', (e) => onChapterChange?.((e as CustomEvent).detail.index)],
      ['error', (e) => onError?.((e as CustomEvent).detail)], ['loadedmetadata', () => onLoadedMetadata?.(node.duration)],
    ];
    map.forEach(([n, h]) => node.addEventListener(n, h));
    return () => map.forEach(([n, h]) => node.removeEventListener(n, h));
  }, [onPlay, onPause, onEnded, onTimeUpdate, onChapterChange, onError, onLoadedMetadata]);
  return (
    <talkie-player ref={el} src={attrs.src} controls={attrs.controls === false ? 'false' : undefined} autoplay={attrs.autoPlay ? '' : undefined}
      start={attrs.start} captions={attrs.captions} poster={attrs.poster} wasm-url={attrs.wasmUrl} class={attrs.className}
      style={{ ...(accentColor ? { '--talkie-accent': accentColor } : {}), ...style } as CSSProperties} />
  );
}
```
